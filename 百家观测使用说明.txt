百家观测 · 百家号内容数据工作台

安装与启动
Windows：运行安装包完成安装，双击桌面「百家观测」快捷方式。
Mac：运行对应芯片版本的 pkg 安装包，从「应用程序」打开「百家观测」。
打开后直接进入工作台，无需注册或登录本地账号。
软件使用独立桌面窗口，运行环境随安装包提供。
点击右上「使用说明」可打开图文 PDF 教程。

百度登录
进入「连接与设置」→「打开百度官方登录窗口」。
桌面版使用软件内的百度官方登录窗口。
可以使用官方页面当前提供的任何登录方式：扫码、短信验证码、账号密码或其他方式。
可用方式由百度决定，受设备、账号和地区影响。
完成登录和官方验证后，软件自动读取该专用窗口的百度 Cookie。
百度接口要求 Cookie 包含 BDUSS 和 Hmery-Time；软件会尝试跳转到百家号主页生成后者。
若百度未生成 Hmery-Time，仍需要手动在百家号主页请求中复制 Cookie 连接。
“已连接”表示登录态已保存，实际接口可用性由同步结果验证。
断开连接会清除保存的 Cookie 与专用窗口缓存，已采集数据保留。

添加监控账号与采集
点击「添加监控账号」，填写需要监控的百家号用户主页链接，再点击「识别并添加」。
软件直接读取该主页资料，并将账号保存到监控列表。添加账号不再使用昵称搜索或百度索引。
重复添加同一主页会定位已有账号，保留已采集作品。
识别后选择采集范围，点击「开始同步」。监控列表中的账号可以随时选择并手动同步。
用户主页格式：https://author.baidu.com/home/数字ID

内容搜索
右上「搜索内容」用于检索作品标题与关键词。本地已采集作品可直接搜索。
在线搜索使用百度公开索引。连接百度后，搜索优先复用软件专用的已登录官方浏览器窗口。
软件会在内部解析内容标题与跳转链接，结果可查看已采集数据或打开原文。
若出现百度安全验证，请在该专用官方窗口自行完成，再点击软件的搜索按钮。

采集
选择监控账号后同步，软件会按原项目接口自动翻页、采集作品与互动数据。
可以选择全部历史作品，或近期 100/500/1000 件。限制数量的任务会明确标为“指定范围完成”，不会标记为全量历史完整。
可以停止同步，采集结果按作品逐条落盘；重新同步从首页开始并更新已有记录。
界面会显示页数、作品数、失败与不完整状态。只有遍历到末页且必要指标完整，才标为完整。
无法获取平台不公开、已删除、受权限限制的数据。

统计
作者：指定作者或全部作者。
时间：近 7/30/90 天、全部，或自定义起止日期。按作品的北京时间发布日期过滤。
手选：在表格勾选作品，再选择「仅统计手选作品」。统计手选与当前筛选条件的交集。
排序：发布时间、阅读/播放、点赞、评论、转发、收藏、直播回放、未读、互动合计、互动率及自定义公式。
缺失值显示 —，排在排序结果末尾。有效作品数量会显示在统计卡片中。
互动合计 = 点赞 + 评论 + 转发 + 收藏；任一项缺失时，合计不可用。
整体互动率使用同时有阅读和完整互动数据的作品：总互动 / 总阅读 × 100。
筛选时间内发布的作品，其数值为最后采集时的累计指标，不能解释为该时间段内新增数值。
该版本不提供历史快照、增量曲线或未公开的后台指标。

自定义统计器
支持指标变量 views、likes、comments、shares、favorites、live_views、unread、interactions。
支持数字、括号、加减乘除，不执行任意代码。除零或所需指标缺失的作品显示 —。
支持先汇总后算公式、逐件求和、平均、最大、最小。
公式可保存、编辑、删除，并作为表格列、排序依据与导出字段。
公式例子：
  加权互动得分：likes + comments * 2 + shares * 3 + favorites * 2
  整体互动率：interactions / views * 100，选择先汇总后计算
  平均阅读量：views，选择逐作品计算后取平均

导出
导出 UTF-8 BOM CSV，兼容 Excel，包含当前范围的作品指标及自定义逐作品计算列。
若选择手选统计，导出范围也为当前筛选内的手选作品。
CSV 空白表示指标未知，而不是零。阅读/播放的含义以百度接口返回口径为准。

本地数据
软件使用一个本地工作台，监控账号、作品和统计器自动保存。
Windows 连接状态使用系统加密；Mac 连接状态使用钥匙串保存。
安装版数据位置：Windows 为 LocalAppData/BaijiaObservatory；Mac 为 ~/Library/Application Support/BaijiaObservatory。
源码开发版的数据在项目 .local 目录。
备份时应关闭软件；加密登录态无法在其他 Windows 用户或电脑直接解密，应重新登录。
演示数据独立于真实数据，包含 3 位虚构作者和 144 件作品，仅用于体验。
